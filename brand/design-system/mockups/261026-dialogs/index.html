Dialogs like the week

Every page is now at the week's size, but the dialogs are still the system's small ones: 416px wide, 44px fields, a 22px title. The app has two kinds: the form dialogs (Add and Edit exercise, Add and Edit food) and the questions (Remove Squats?, Replace next week's plan?, Sign out now?). Both options size them from the screen like the pages:

  • Title 27u, like the row names and Settings' headings.
  • Labels and text 19u; fields, segments, the counter and buttons 60u tall, as on Settings.
  • Padding 32u, 24u between fields.
  • The same tokens, scrim and focus rules; nothing new to measure for contrast.
  • So Add exercise fits a 1920×1200 screen at that size, “Times a week” moves up beside Reps count and Weight, and the Note comes last. Where the row is too narrow it wraps.

They differ in where a form dialog sits. Decided: A, centred (K55).
