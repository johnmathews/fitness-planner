Lucide outline icons (ISC licence), drawn at 1.5px stroke. These files are stroked in light-theme `ink` (#1f1d1a) because an `<img>` cannot inherit colour; in the app and in previews, use the Lucide component or an inline SVG with `stroke="currentColor"` so the icon follows `ink`, `ink-secondary`, `error-ink` or `caution-ink`.

Size: 20px inside buttons and icon buttons, 16px beside text. An icon never carries meaning alone: pair it with words or an accessible label.

| Icon | Use |
| --- | --- |
| check | The selected ink; a success message |
| circle-alert | Errors, with `error-ink` |
| triangle-alert | Caution messages, with `caution-ink` |
| info | Information messages |
| chevron-left, chevron-right | Previous and next week |
| settings | Opens Settings |
| x | Closes a dialog or popover; clears a search |
| plus, minus | Stepper buttons; add a row |
| pencil | Edit a row |
| trash-2 | Remove a row (always confirmed) |
| search | Search field |
| cloud-off | Offline banner |
| refresh-cw | Sync conflict banner: reload |
| sun, moon, monitor | Theme segments: Light, Dark, System |
| calendar-days, list | Switch between the week and the phone's Today list |
| sticky-note | Add or open a note |
